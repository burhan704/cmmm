# Carry Me — React + Vite Landing Page

বাংলা কনটেন্টসহ responsive dark-theme e-commerce landing page।

## চালানোর নিয়ম

1. Node.js (LTS) ইনস্টল করুন।
2. এই প্রজেক্ট ফোল্ডারে টার্মিনাল খুলুন।
3. চালান:

```bash
npm install
npm run dev
```

4. টার্মিনালে দেখানো localhost লিংক ব্রাউজারে খুলুন।

Production build:

```bash
npm run build
```

## অন্তর্ভুক্ত ফিচার

- Responsive navigation ও mobile menu
- পণ্য সার্চ এবং ক্যাটাগরি ফিল্টার
- Add to cart, quantity update, remove item ও subtotal
- Newsletter form interaction
- Toast notification
- React + Vite, আলাদা CSS, lucide-react icons

## নোট

পণ্য/রিভিউর ছবি অনলাইন Unsplash URL থেকে লোড হয়। বাস্তব অর্ডার নেওয়ার জন্য checkout button-কে পেমেন্ট/অর্ডার backend-এর সঙ্গে সংযুক্ত করতে হবে। ফোন, ইমেইল ও অফারের লেখা ডেমো হিসেবে দেওয়া।
